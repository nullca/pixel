# Backlog

## ทำต่อก่อน (เรียงตามความสำคัญ)
1. **แยกไฟล์เป็นโมดูล** — ย้าย `game/index.html` ไปเป็น Vite + TypeScript แยกตามระบบ (world, render, npc, economy, ui, audio, features/*)
   ทำแบบค่อยเป็นค่อยไป: ย้ายทีละ section แล้วรัน smoke test ทุกครั้ง
2. **เชื่อม backend** — แทนที่ artifact runtime (`window.claude.use`) ด้วย `api/` + KID login (ดู `api/README.md` หัวข้อ Rollout: shadow mode ก่อน)
3. **หน้า admin จริง** — ย้ายแผง "ตั้งค่าเศรษฐกิจเกม" และปุ่มดีบักออกจากเกม ไปไว้หลังสิทธิ์แอดมินใน backend
4. **รายงานให้ HR/IT** — อัตราตอบถูกตามหัวข้อ คำถามที่ผิดบ่อย ผู้เล่นรายวัน

## ไอเดียที่คุยไว้แล้ว
- เยี่ยมห้องทำงานของเพื่อนร่วมทีม (ต้องเก็บข้อมูลห้องขึ้นเซิร์ฟเวอร์)
- ส่งของขวัญ / ข้อความสำเร็จรูประหว่างผู้เล่น
- อีเวนต์ตามเทศกาลจริง (สงกรานต์ ลอยกระทง ปีใหม่)
- ตารางชีวิต NPC และค่าความสนิท
- เนื้อเรื่องซีซันถัดไป (ตอนนี้มี 4 บท ปลดล็อกสัปดาห์ละบท เริ่ม 1 ต.ค. 2026)
- โหมดเครื่องสเปกต่ำ, ขนาดตัวอักษร, ภาษาอังกฤษ

- เหรียญ/ไอเทมยังอยู่ฝั่ง client แก้ผ่าน DevTools ได้ จนกว่าจะเชื่อม `api/`
- แผงตั้งค่าเศรษฐกิจและปุ่มดีบักเปิดให้ทุกคนเห็น (ใช้ทดสอบเท่านั้น)
